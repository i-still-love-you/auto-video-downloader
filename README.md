# Auto Video Downloader (PC)

내장 브라우저로 웹 페이지의 동영상 소스를 자동 감지해 내려받는 데스크톱 앱입니다. Electron + TypeScript + React 로 만들었으며
Windows / macOS / Linux 에서 동작합니다. 모바일 비디오 다운로더 앱의 기능 구성을 PC 환경에 맞게 옮긴 것입니다.

## 주요 기능

| 영역 | 내용 |
| --- | --- |
| 동영상 자동 감지 | 내장 브라우저(WebContentsView)의 네트워크 응답을 감시해 m3u8(HLS), mpd(DASH), mp4/webm/mkv/mov/flv 등 직접 파일을 찾아냅니다. 여기에 더해 탭 preload 가 페이지를 스캔해 재생 전에도 video/source 태그, og:video 메타, JSON-LD, 인라인 스크립트의 매니페스트 주소, 미디어 링크, 임베드 iframe 을 "페이지에서 발견" 항목으로 올리고, 주소가 있는 video 태그는 메타데이터만 자동 요청해 감지합니다. 사이드바의 "이 페이지 분석" 버튼은 현재 페이지 주소를 yt-dlp 로 분석합니다. Referer / Cookie / User-Agent 를 함께 저장해 다운로드 시 그대로 전달합니다. 감지 목록은 브라우저 오른쪽에 항상 고정된 사이드바로 표시되며(즐겨찾기·기록·광고 차단 패널은 그 위에 잠깐 펼쳐짐), 감지 항목에는 이미 받은 파일(다운로드됨)과 진행 중인 항목이 배지로 표시되고, "바로 받기" 버튼은 분석 창 없이 기본 화질 설정으로 즉시 큐에 넣습니다. |
| 다운로드 엔진 | 직접 파일: Range 기반 멀티 연결 다운로드 + 상태 파일로 이어받기. HLS: 자체 m3u8 파서(마스터/미디어, AES-128, EXT-X-MAP, BYTERANGE, 별도 오디오 그룹) + 병렬 세그먼트 다운로드 + ffmpeg 병합. 페이지 주소/DASH: yt-dlp 위임. |
| 화질 선택 | HLS 변형(해상도/비트레이트)과 yt-dlp 형식 목록에서 고르거나, 설정의 기본 화질(최고/1080p/720p/480p/최저)로 자동 선택합니다. |
| 큐 관리 | 동시 다운로드 수 제한, 일시정지/재개/취소/재시도, 속도·남은 시간·세그먼트 진행률, 로그 보기, 파일 열기/폴더에서 보기. 완료·취소된 항목은 최근 500개까지만 목록에 남기고 오래된 것은 자동으로 정리합니다(파일과 다운로드 이력은 그대로). 목록은 100개씩 "더 보기"로 펼칩니다. |
| 다운로드 이력·중복 방지 | 완료된 영상마다 영상 페이지 주소, 휘발성 쿼리(토큰·난수)를 뺀 소스 주소, 제목, 크기, 길이(ffprobe), 파일 경로를 `library.json` 에 남깁니다. 다운로드 목록을 정리하거나 파일을 다른 곳으로 옮겨도 이력은 남습니다. 중복은 두 등급으로 판정합니다. 같은 페이지 또는 같은 소스 주소면 "확실", 크기와 길이가 같거나(크기만 같아도 1MB 이상이면) 같은 사이트의 같은 제목이면 "유력". 분석 창은 "이미 받은 영상입니다 (사유·날짜·크기·길이·파일 있음/없음)" 를 보여 주고 "그래도 다운로드" 로 받을 수 있으며, 감지 목록에는 "이미 받음"/"이미 받은 듯" 배지가 붙습니다. 자동 다운로드는 확실한 중복과 유력한 중복을 기본으로 건너뛰며, 옵션에서 유력한 중복 건너뛰기를 끌 수 있습니다. 다운로드 페이지의 "이력" 창에서 검색·폴더에서 보기·페이지 열기·삭제·전체 삭제를 할 수 있고, 파일 이름을 바꾸면 이력의 경로도 따라갑니다. |
| 자동(일괄) 다운로드 | 검색 결과·카테고리 같은 목록 페이지 주소 하나로 페이지를 넘겨 가며 영상을 모두 받습니다. 목록 페이지를 숨김 창에 렌더링해 영상 페이지 링크(제목·썸네일·길이)와 다음 페이지 링크(rel=next, "다음" 링크, 숫자 페이지네이션, 주소의 페이지 번호)를 찾고, 각 영상 페이지에서 실제 동영상 주소를 찾아 큐에 넣습니다. 주소 찾기는 KVS 계열 사이트의 플레이어 설정(flashvars, base64·license_code 해제) → 페이지 태그/스크립트(og:video, video/source, JSON-LD, m3u8/mp4) → yt-dlp 순서로 시도합니다. 시작 페이지, 최대 페이지 수, 최대 영상 수, 화질, 페이지 간 대기, 제목·주소 필터(정규식), 이미 받은 영상 건너뛰기 옵션이 있고, 시작 전 "미리 보기"로 첫 페이지에서 잡히는 영상을 확인할 수 있습니다. 목록 페이지는 필요할 때만 한 장씩 읽고 큐에는 동시 다운로드 수 + 2개까지만 미리 넣어 다운로드 목록이 불어나지 않습니다. 작업은 `batch.json` 에 저장되어 앱을 다시 켜도 이어서 할 수 있으며(재시작 직후에는 작업과 그 다운로드가 모두 일시정지 상태이고, "이어서"를 누르면 일시정지된 다운로드도 함께 깨웁니다), 일시정지/중지/실패 재시도/항목 건너뛰기, 브라우저 사이드바 버튼과 우클릭 메뉴("이 페이지의 영상 목록 자동 다운로드")로 바로 시작할 수 있습니다. 목록 페이지를 읽지 못하면(응답 시간 초과 등) 작업을 끝내지 않고 5분 뒤에 같은 페이지를 다시 읽으며, 그동안 이미 찾은 항목은 계속 받습니다. "지금 다시 확인" 버튼으로 기다리지 않고 바로 읽을 수 있고, 목록 읽기 실패로 끝난 작업은 "강제로 이어서"로 남은 페이지부터 다시 읽습니다. 같은 사이트를 보고 있는 탭이 있으면 그 탭의 세션(쿠키·로그인)을 빌립니다. |
| 내장 브라우저 | 탭, 주소창, 12개 검색엔진, 즐겨찾기, 방문 기록, 우클릭 메뉴(동영상 다운로드, 새 탭에서 열기), 단축키(Ctrl+T/W/L/R, Ctrl+1~9 탭 이동, Ctrl+Shift+T 닫은 탭 열기, Alt+←/→, F12). 탭 우클릭 메뉴(새로고침, 복제, 다른 탭 모두 닫기, 오른쪽 탭 닫기, 닫은 탭 다시 열기). 브라우저의 파일 다운로드도 관리자로 가로챕니다. |
| 탭 세션 격리 | 새 탭마다 메모리 전용 세션을 만들어 쿠키·저장소·캐시를 탭 간에 공유하지 않습니다. 페이지가 연 팝업, 새 탭 링크, 복제 탭은 원래 탭 세션을 물려받습니다(설정에서 끌 수 있음). 세션이 메모리에만 있어 앱을 닫으면 쿠키가 모두 사라지고, 탭을 닫으면 그 세션 데이터를 즉시 비웁니다. 다운로드는 영상을 감지한 탭의 쿠키를 사용합니다. |
| 팝업 차단 | 새 창 요청을 세 겹으로 검사합니다. 최근 5초 안에 사용자 입력이 없거나 같은 입력으로 두 번째 창이면 차단, 주소가 광고 필터에 걸리면 차단, 0.5초 안에 원래 탭이 다른 페이지로 이동하면(탭언더) 차단합니다. 차단 시 "열기" 버튼이 있는 토스트를 띄우고, 방패 패널에서 차단 목록 확인과 사이트별 허용을 할 수 있습니다. |
| 세션 복구 | 열린 탭과 각 탭의 뒤로/앞으로 기록을 `session.json` 에 저장하고 다음 실행 때 복원합니다. 활성 탭만 즉시 로드하고 나머지는 선택할 때 로드합니다. 방문 기록과 즐겨찾기는 별도 파일에 영구 저장됩니다. |
| 광고·추적 차단 | Ghostery 차단 엔진(uBlock Origin/AdGuard 필터 문법 호환)을 내장 브라우저 세션에 연결. AdGuard Base/Tracking/Social/Annoyances, List-KR(한국어), EasyList, EasyPrivacy, uBlock filters/unbreak 목록 선택, 24시간마다 자동 갱신, 사용자 규칙, 사이트별 끄기, 탭별·전체 차단 수 표시, 코스메틱(요소 숨김) 필터, AdGuard DNS(DoH) 옵션. 필터 파싱은 worker thread 에서 수행하고 직렬화 캐시로 빠르게 시작합니다. |
| 내장 플레이어 | 다운로드 전 온라인 재생(HLS 는 hls.js + 프록시), 로컬 파일 재생, 배속(0.5x~3x), 화면 회전, 반복, 전체 화면, 재생 목록. |
| 파일 관리자 | 다운로드 폴더 목록/격자 보기, 썸네일, 재생, 이름 변경, 휴지통 삭제, 개인 폴더로 이동. |
| 썸네일 | ffmpeg 로 로컬 파일과 원격 동영상(mp4, m3u8)의 프레임을 뽑아 캐시합니다. 다운로드 목록, 파일, 감지 목록, 분석 창, 재생 목록, 개인 폴더(암호화 저장)에 표시되며, ffmpeg 가 없으면 재생 가능한 로컬 파일은 앱 안에서 canvas 로 캡처합니다. |
| 개인 폴더 | PIN(scrypt) 으로 보호되는 AES-256-GCM 암호화 폴더. 추가/재생/내보내기/삭제/PIN 변경. |
| 설정 | 저장 폴더, 동시 다운로드 수, 연결 수, 기본 화질, MP4 변환, 감지 최소 크기, 검색엔진, 홈페이지, 도구 경로, 자동 업데이트. |
| 도구 자동 설치 | 설정 > 도구에서 yt-dlp / ffmpeg 를 내려받아 사용자 데이터 폴더에 설치합니다. PATH 나 앱 번들의 바이너리도 자동 탐색합니다. |
| 배포 | electron-builder(NSIS / DMG / AppImage) + electron-updater 자동 업데이트 설정. |

## 요구 사항

- Node.js 20 이상 (개발 환경은 Node 24 로 검증)
- yt-dlp, ffmpeg: 필수는 아니지만 사이트 페이지 주소 분석(yt-dlp)과 HLS 병합/MP4 변환(ffmpeg)에 필요합니다. 앱 안에서 자동 설치할 수 있습니다.
- Windows 10 이상 / macOS 11 이상 / 최신 Linux

## 개발

```bash
npm install
npm run dev        # Vite 개발 서버 + Electron 실행 (HMR)
npm run typecheck  # 메인/프리로드/렌더러 타입 검사
npm run build      # out/ 에 번들 생성
npm run preview    # 빌드 결과로 Electron 실행
```

- 개발 모드는 React 개발 빌드라 프로덕션보다 훨씬 느립니다. 자동 다운로드처럼 갱신이 잦은 작업을 오래 돌릴 때는
  `npm run build && npm run preview` 또는 설치 파일로 실행하는 것이 좋습니다. (React 개발 빌드가 렌더마다 남기는
  `performance.measure` 항목이 쌓여 메모리를 잠식하는 문제는 `main.tsx` 에서 주기적으로 비워 막아 두었습니다.)
- UI 렌더러가 메모리 부족 등으로 죽으면 창이 검게 변하는데, 이때 메인 프로세스가 UI 를 자동으로 다시 불러옵니다.
  다운로드와 자동 다운로드는 메인 프로세스에서 돌므로 중단되지 않습니다. 메인 프로세스에서 잡히지 않은 예외가 나도
  Electron 의 모달 오류 창(닫을 때까지 모든 처리가 멈춤) 대신 콘솔에 기록하고 토스트로 알린 뒤 계속 진행합니다.

## 배포 패키지 만들기

```bash
npm run fetch-tools   # yt-dlp / ffmpeg 를 resources/bin 에 내려받아 설치 파일에 동봉 (선택)
npm run dist:win      # dist/ 에 NSIS 설치 파일 생성
npm run dist:mac      # DMG / ZIP
npm run dist:linux    # AppImage
```

- 아이콘은 `build/icon.png`, `build/icon.ico` 입니다. 바꾸려면 같은 이름으로 교체하세요.
- 코드 서명(Windows): 환경 변수 `CSC_LINK`(.pfx 경로 또는 base64) 와 `CSC_KEY_PASSWORD` 를 설정하면 electron-builder 가 자동으로 서명합니다.
- 공증(macOS): `APPLE_ID`, `APPLE_APP_SPECIFIC_PASSWORD`, `APPLE_TEAM_ID` 를 설정합니다.
- 자동 업데이트: `electron-builder.yml` 의 `publish.owner` 를 본인 GitHub 계정으로 바꾸고 `GH_TOKEN` 을 설정한 뒤
  `npx electron-builder --win --publish always` 로 릴리스에 올리면 설치된 앱이 시작 시 업데이트를 확인합니다.

## 프로젝트 구조

```
src/
  shared/            메인·렌더러 공용 타입과 IPC 채널 이름, 중복 판정 규칙(dedupe.ts)
  preload/           contextBridge 로 노출하는 window.api
  main/
    index.ts         앱 부트스트랩, 창 생성, 세션/권한, 종료 처리
    ipc.ts           모든 IPC 핸들러
    protocols.ts     media:// (로컬 파일 Range 스트리밍), mproxy:// (헤더 포함 원격 프록시, m3u8 URL 재작성)
    settings.ts      설정 저장소
    browser/
      tabs.ts        WebContentsView 탭 관리, 단축키, 우클릭 메뉴, HTML 전체 화면
      sniffer.ts     webRequest 기반 동영상 감지와 분류 규칙
    batch/
      manager.ts     자동(일괄) 다운로드 작업 관리: 목록 페이지 순회, 항목 해석, 큐 투입, 영속화
      crawler.ts     목록 페이지를 숨김 창에 렌더링해 링크를 뽑는 로더
      pageScript.ts  페이지 안에 주입되는 목록·다음 페이지 추출 스크립트 (외부 참조 금지)
      extractors.ts  영상 페이지에서 실제 주소 찾기 (KVS flashvars, og:video/video 태그/스크립트), 화질 선택
    downloads/
      manager.ts     큐/상태/속도 계산/영속화, URL 분석 라우팅
      library.ts     다운로드 이력 저장과 중복 판정 (규칙은 shared/dedupe.ts)
      net.ts         다운로드용 fetch, 세션 쿠키 → 헤더/Netscape 파일
      engines/
        http.ts      멀티 연결 + 이어받기
        hls.ts       m3u8 파서 + 세그먼트 다운로드 + AES-128 복호화 + ffmpeg 병합
        ytdlp.ts     yt-dlp 분석/다운로드, 진행률 파싱
        ffmpeg.ts    리먹스/병합 실행
    vault/vault.ts   PIN 보호 암호화 폴더
    tools/binaries.ts 도구 탐색/버전/자동 설치
    storage/         JSON 저장소, 방문 기록/즐겨찾기
    updater.ts       electron-updater 연동
    smoke.ts         VDL_SMOKE=1 자동 점검 모드 (VDL_DEBUG_SNIFF=1 을 함께 주면 감지기의 응답별 판정 과정이 리포트의 sniffLog 에 남는다)
  renderer/src/
```

## 동작 원리 요약

1. 브라우저 탭은 별도 세션(`persist:browser`)에서 동작하며, 이 세션의 `webRequest.onHeadersReceived` 에서 Content-Type 과 URL 확장자를 보고
   HLS/DASH/직접 파일을 분류합니다. 세그먼트(.ts/.m4s)나 작은 파일은 걸러냅니다.
2. 감지 항목의 "다운로드" 를 누르면 메인 프로세스가 재생목록을 분석해 화질 목록을 돌려주고, 선택 결과로 작업을 큐에 넣습니다.
3. 작업은 엔진(http / hls / ytdlp)이 실행하며, 진행률은 250ms 단위로 렌더러에 전달되고 JSON 파일에 저장되어 앱을 다시 켜도 이어받을 수 있습니다.
4. 온라인 재생은 `mproxy://` 프로토콜이 저장된 헤더로 원본을 대신 받아오고, m3u8 안의 주소를 프록시 주소로 바꿔 hls.js 가 CORS 없이 재생하게 합니다.
5. 로컬 파일 재생은 `media://` 프로토콜이 Range 요청을 지원하며 다운로드 폴더와 개인 폴더 임시 파일만 허용합니다.
6. 자동 다운로드는 목록 페이지를 숨김 창(BrowserWindow, 이미지 비활성)에 로드해 DOM 에서 영상 링크와 다음 페이지를 찾고,
   영상 페이지는 세션의 `fetch` 로 HTML 만 받아 플레이어 설정/태그에서 주소를 뽑습니다. 못 찾으면 yt-dlp 로 넘깁니다.
   큐에 넣을 준비가 된 항목이 6개 아래로 내려갈 때만 다음 목록 페이지를 읽고, 페이지에 영상 링크가 하나도 없거나
   다음 링크를 찾지 못하면(주소에 페이지 번호가 있으면 번호를 올려 한 번 더 시도) 끝냅니다. 페이지 읽기가 실패하면
   끝내지 않고 5분 뒤 같은 페이지를 다시 읽습니다.

## 제한 사항과 안내

- User-Agent 는 Electron 기본값에서 앱 이름 토큰만 뺀 값(`... Chrome/xx Electron/xx Safari/537.36`)이고, UI 렌더러를 포함한
  모든 세션과 다운로드·yt-dlp·썸네일이 같은 값을 씁니다(`main/index.ts` 의 `browserUserAgent`). Electron 토큰까지 지워 순정
  Chrome 처럼 꾸미거나 세션마다 다른 UA 를 쓰면 Cloudflare 보안 확인("Performing security verification")이 끝나지 않으므로
  바꾸지 마세요. 보안 확인은 탭 세션마다 한 번씩 거치고, 탭 세션이 메모리 전용이라 앱을 다시 켜면 다시 확인합니다.
- DRM(Widevine, FairPlay, SAMPLE-AES 등) 으로 보호된 콘텐츠는 감지 단계에서 제외되거나 오류로 처리되며 지원하지 않습니다.
- 라이브(종료되지 않은) HLS 스트림은 다운로드 대상이 아닙니다.
- 내장 플레이어는 Chromium 이 디코딩할 수 있는 코덱만 재생합니다. 그 외 형식은 "기본 프로그램으로 열기" 를 사용하세요.
- 콘텐츠의 저작권과 각 사이트의 이용 약관을 준수해 주세요. 개인적인 용도로만 사용하시기 바랍니다.
